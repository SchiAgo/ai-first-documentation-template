# AI Code Generation Rules

## Regole Generali

Ogni codice generato deve:

- essere tracciabile
- essere coerente con il TRD
- rispettare le ADR
- rispettare il modello dati

---

## Backend

Verificare:

- API
- Entità
- Flow

---

## Frontend

Verificare:

- Design System
- Flow
- Requisiti

---

## Database

Verificare:

- Data Architecture
- ADR

---

## Test

Ogni funzionalità deve prevedere:

- Unit Test
- Integration Test
- E2E Test quando applicabile
