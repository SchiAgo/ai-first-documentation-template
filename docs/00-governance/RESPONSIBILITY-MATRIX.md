# Responsibility Matrix

| Documento           | Proprietario       |
| ------------------- | ------------------ |
| PRD                 | Product Owner      |
| TRD                 | Software Architect |
| Application Flows   | Solution Architect |
| Design System       | UX/UI Designer     |
| Data Architecture   | Database Architect |
| Implementation Plan | Project Manager    |
| ADR                 | Architecture Board |

---

## In caso di conflitto

Funzionalità → PRD

Tecnologia → TRD

Dati → Data Architecture

UI/UX → Design System

Pianificazione → Implementation Plan

Decisioni → ADR
