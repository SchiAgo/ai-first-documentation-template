# Document Ownership

## Scopo

Definire il responsabile principale di ogni documento.

---

| Documento           | Proprietario       |
| ------------------- | ------------------ |
| PRD                 | Product Owner      |
| TRD                 | Software Architect |
| Application Flows   | Solution Architect |
| Design System       | UX/UI Designer     |
| Data Architecture   | Database Architect |
| Implementation Plan | Project Manager    |
| ADR                 | Architecture Board |

---

## Responsabilità

Il proprietario:

- approva le modifiche
- mantiene la coerenza
- approva le review
- garantisce la qualità

---

## Conflitti

In caso di conflitto:

Funzionalità → PRD

Tecnologia → TRD

Dati → Data Architecture

UI → Design System

Roadmap → Implementation Plan

Decisioni → ADR
