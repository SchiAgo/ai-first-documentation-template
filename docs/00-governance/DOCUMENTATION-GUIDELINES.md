# Documentation Guidelines

## Scopo

Definire le regole ufficiali per la creazione, manutenzione e revisione della documentazione.

---

## Principi Fondamentali

### Single Source of Truth

Ogni informazione deve essere definita in un solo documento.

---

### No Duplication

È vietato duplicare informazioni tra documenti.

I documenti devono riferirsi tramite ID e tracciabilità.

---

### Tracciabilità Obbligatoria

Ogni elemento deve poter essere collegato ai documenti correlati.

---

### Consistenza Terminologica

Lo stesso concetto deve mantenere lo stesso nome in tutto il repository.

---

### AI Friendly Documentation

La documentazione deve essere strutturata per essere interpretata correttamente da sistemi AI.

---

## Gerarchia delle Verità

| Documento           | Responsabilità         |
| ------------------- | ---------------------- |
| PRD                 | Verità Funzionale      |
| TRD                 | Verità Tecnica         |
| Application Flows   | Verità Comportamentale |
| Design System       | Verità UI/UX           |
| Data Architecture   | Verità dei Dati        |
| Implementation Plan | Verità Operativa       |
| ADR                 | Verità Decisionale     |

---

## Regola Fondamentale

In caso di conflitto prevale sempre il documento proprietario dell'informazione.
