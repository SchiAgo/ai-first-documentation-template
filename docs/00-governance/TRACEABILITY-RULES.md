---

## Regole

Ogni FR deve avere almeno un FLOW.

Ogni FLOW deve avere:

- almeno una ENT
- almeno una API
- almeno una UI

Ogni EPIC deve derivare da un requisito.

Ogni TASK deve appartenere ad una EPIC.
